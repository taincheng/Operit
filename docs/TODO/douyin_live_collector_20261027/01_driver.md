# 01 直播间驱动

## 页面与定位

一律按文案（text / content-desc）定位，resource-id 只用于辅助判断。可见性必须并进匹配条件，不能先取首个匹配再判可见：抖音的回收视图里会留着上一条的节点，`bounds` 会退化成 `x2 < x1` 或落到屏幕外。

### 搜索页

- 就绪标记：顶部标签行出现 `综合`
- 标签行：`HorizontalScrollView`，子节点是 `text` 为标签名的 Button（id `android:id/text1`），y 在 258 到 320 之间
- 标签顺序会变：2026-10-28 是 `用户/团购/商品/直播/音乐/话题/图文`，「直播」初始被右边缘裁掉（`[877,258][908,320]`），要左滑标签行（`850,285 → 260,285`，400ms）；2026-11-02 变成 `综合/视频/直播/图文/商品/店铺/团购/用户`，「直播」直接落在 `[400,258][484,320]`，不用滑。驱动按「中心 x ≤ 850 且在屏内」判断，两种版式都不用改
- 点击后等 6 秒列表加载；列表首卡标题 y≈534、封面 681–1624

### 直播列表

- **不能读**：外部 `uiautomator dump` 在列表上稳定报 `could not get idle state`（预览在播放）。采集脚本走无障碍 provider，和视频包读搜索页同一通道
- **列表节点树会变**：2026-10-28 打印确认卡片全是 `FrameLayout` / `ImageView` / `ViewGroup`，`text` 全空、`clickable` 全 false；2026-11-02 同一台设备同一版本（抖音 37.8.0）上，「直播中」角标、卡片标题 desc 与 `clickable=true` 的容器又都出现在树里。**不能按文案找卡**，只能按布局
- 按布局找卡：封面横向几乎占满屏（左右各缩进 45，宽 990/989），点它与内容区的**交集中心**。不能要求整张封面都在屏内：上滑后封面会停在 y=354（标签行下沿）或被底部裁掉，旧规则「y1 ≥ 400 且 y2 ≤ 屏高-150」会把这两类卡全部排除（2026-11-02 实测：一次只采到 1 间就误报「列表到底」）
- 团购广告是 480–525 高的横幅，交集高门槛（30% 屏高 = 720）能排除；点进广告会打开商品页，按页面内容（没有搜索标签行）判断后返回列表
- 标签行刚滑完有惯性：第一次点「直播」有时只止住滚动、不选中，页面停在「综合」，内容区一直空着，还会把综合页残留节点当成直播卡。标签要**点两次**，中间重读节点
- 进房判定：出现 `content-desc` 以 `本场点赞` 结尾的 Button；等 20 秒（第二张卡首次进房比首卡慢，10 秒会误判）
- 回列表：返回键，**用页面内容确认**：搜索标签行在、且房间标记不在。2026-10-28 实测两次返回后仍停在直播间（第一次只关掉分享面板），这时再上滑会滑在房间里。**不能读 `page.activityName`**：2026-11-02 实测它给的是窗口根类名（直播间 `com.lynx.tasm.behavior.KeyboardMonitor`、搜索页 `androidx.compose.ui.platform.ComposeView`），一次返回键都不会按
- 下一张卡：从 `(540,2000)` 滑到 `(540,1000)`（1000px），等 1.5 秒，再按布局找当前可视卡的中心点
- 到底：列表出现文本 `暂时没有更多了`；直播结果会随时间变化，同一关键词不同轮次可能看到不同房间数
- 滑动失败/没换卡：先确认当前不在直播间，再重试；进房后的主播名与上一个房间相同，返回后再滑一次，最多 3 次；3 次还不行按 `search_exhausted` 收片
- 页面读取偶发失败：宿主 `getPageInfo` 内部只重试三次、间隔 300ms，转场时会连续失败（`Failed to retrieve UI data via accessibility service`）。`readRoot` 按次数重试（0.5s/1s 退避），一次失败不该终止整片

### 直播间

- 房间标记：`content-desc` 以 `本场点赞` 结尾，形如 `宠宝圈宠物医院连锁-官方号1.2万本场点赞`
  - 主播名 = desc 去掉末尾 `(\d+(?:\.\d+)?)(万?)本场点赞`
  - 本场点赞 = 那个数字（`万` 乘 10000）
  - 用「从末尾取最后一个数字串」的正则，避免主播名里本身带数字时切错
- 在线观众：`content-desc` 匹配 `^(\d+(?:\.\d+)?)(万?)在线观众$`
- 更多面板入口：`content-desc` 以 `更多面板` 开头
- 面板项：`text` 精确等于 `分享链接`。**面板高度会随联系人行/功能项变化**，实测同一台设备上出现过 `[445,1799]`、`[231,1799]`、`[321,1390]` 三种位置；坐标写死必错，只能按文案找
- 面板项不在可视区（中心 y ≥ 屏幕高 - 150）时，把面板往上带（`540,2150 → 540,1850`），最多 3 次
- 复制成功判据：出现 `text` 含 `链接已复制成功，去粘贴分享` 的面板；出现后按返回键关面板
- 关面板后必须等房间标记重新出现再切 App，避免把「面板还在」当成房间

## 取链与身份

剪贴板口令原文：

```
2- #在抖音，记录美好生活#【<主播名>】正在直播，来和我一起支持Ta吧。复制下方链接，打开【抖音】，直接观看直播！ https://v.douyin.com/<短码>/ ...
```

- 短链正则：`/https?:\/\/v\.douyin\.com\/[^\s]+/`
- 主播名：`/【(.+?)】/`
- `room_id`：GET 短链（跟随 302）后最终页里的 `/fromShareRoomId="(\d+)"/`
- `author_id`（主播抖音号）：同一页 owner 对象里的 `\"displayId\":\"([^"\\]*)\",\"withCommercePermission\":`
  - 锚点必须是 `withCommercePermission`：它只出现在 owner 对象里；页面里别的用户也有 `displayId`（空串或他人），全页取第一个会取错人
  - 2026-10-30 真机：牙贝恩的 `displayId=70296714883`，与主播主页「抖音号：」完全一致；数值账号上它等于 `shortId`
  - 主播主页 UI 也能取到（房间左上角头像 → 简介卡头像 → `UserProfileActivity`），但 `王利梅口腔医院` 这类账号主页显示「商家认证账号」、整页没有「抖音号」节点，按 UI 采会漏，所以不作为取数路径
- 短码每次分享都变，**不能当身份**；`room_id` 才是。同一房间两次分享实测短码不同、`room_id` 相同

解析失败直接抛错，不退回用短码当身份：退回去等于继续写重复行，而且这种错误要过很久才在数据上看出来。

## 剪贴板

直播间评论框最多 50 字，口令里的 URL 在第 80 字之后，粘进去就被截断，所以不能用评论框回读。

**不能用「切到 Operit 前台再读」**：2026-10-28 实测，切到宿主再 `startApp` 回抖音，抖音落到 `MainActivity` 推荐流，直播间 `DetailActivity` 已经不在，采集直接失败。

改用 shell 在抖音保持前台时读：

1. `Tools.System.shell("service call clipboard 4 s16 com.android.shell s16 null i32 0 i32 0")`
2. 解析 `service call` 的 Parcel hexdump：每个 8 位十六进制按小端拼回字节
3. 用 ASCII 短链做锚点，向两侧扩到不可打印字节，再按 UTF-8 解码出完整口令

原因：Android 10 起普通应用只有获得焦点时才能读剪贴板，但 shell（UID 2000，Shizuku/调试器档）不受这条限制；抖音在前台也能拿到完整口令。设备权限档是 `DEBUGGER`，`Tools.System.shell` 可用。

宿主包名用 `/proc/self/maps` 推导：

```text
/data/app/~~xxx/com.ai.assistance.operit.debug-yyy==/base.apk
```

`/proc/self/cmdline` 含 NUL 字节，宿主的 `read_file_full` 会按二进制拒绝；`maps` 是纯文本。宿主没有暴露「当前 App 包名」的 API。

读不到口令、口令里没有短链、短链解析不到 `room_id`，都抛错并带上现场，不写这条记录。

## 失败处理

- 任一关键节点超时即抛错，错误里带当前包名、Activity、节点数与前 10 条文本
- 读无障碍树偶发失败按「还没就绪」退避重试到超时，不当作页面不存在
- 所有重试都有次数上限，且判定是否真的前进（主播名/房间标记），不允许无限滑动
- 进房失败、面板项找不到、复制成功面板不出现：如实报错

## 与视频驱动的差异

| 项 | 视频 | 直播间 |
| --- | --- | --- |
| 标签 | 视频 | 直播（需先左滑标签行） |
| 进入 | 点时长角标 | 按封面布局找卡，点中心（节点树无文案） |
| 分享入口 | 详情页底栏「分享」按钮 | 底栏「更多面板」→「分享链接」 |
| 复制判据 | 提示 `链接已复制成功` | 面板 `链接已复制成功，去粘贴分享` |
| 回读剪贴板 | 评论输入框粘贴回读 | **shell `service call clipboard`**（评论框限 50 字；切前台会丢直播间） |
| 身份 | canonical `/video/<id>` | 最终页 `fromShareRoomId` |
| 遍历 | 详情页内滑，按页约束 | 回列表滑一张卡再进 |
